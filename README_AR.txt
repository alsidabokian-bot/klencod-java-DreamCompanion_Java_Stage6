رفيق الأحلام الواعية - الإصدار النهائي 1.2 (Java Native)
========================================================

محتويات الإصدار:
- تذكيرات يومية بفحوصات الواقع مع اختيار وقت التذكير.
- فترة هدوء قابلة للتحديد لمنع الإشعارات في وقت النوم.
- إعادة جدولة التذكير بعد إعادة تشغيل الهاتف.
- دفتر أحلام محلي مع عنوان وتفاصيل وتاريخ لكل تدوينة.
- نقاط تحفيزية: 10 نقاط لكل حلم، وشارات عند 1 و5 و10 أحلام.
- إمكانية حذف جميع تدوينات الأحلام بعد تأكيد واضح.
- واجهة عربية باتجاه RTL وألوان ليلية.

طريقة البناء في Klencod IDE:
1. فك ضغط DreamCompanion_Java_Stage6.zip.
2. افتح المجلد الرئيسي الذي يحتوي settings.gradle.
3. انتظر مزامنة Gradle ثم نفّذ Build أو Run.
4. اسمح بالإشعارات من نافذة التطبيق أو إعدادات Android.
5. فعّل التذكيرات واختر وقتاً خارج فترة الهدوء لاختبار الإشعار.

ملاحظات:
- هذا مشروع Android Java مصدري وليس ملف APK.
- يحتاج إلى اتصال إنترنت عند أول مزامنة Gradle لتنزيل إضافات البناء إن لم تكن مخزنة.
- لم تتوفر بيئة Android SDK/Gradle هنا لتنفيذ بناء فعلي أو اختبار على هاتف؛ لذلك يجب تجربة البناء في Klencod IDE.
- يستخدم التطبيق SharedPreferences لحفظ الإعدادات والأحلام محلياً على الجهاز.
- التذكيرات تستخدم منبهاً غير دقيق لتقليل متطلبات صلاحيات المنبهات الدقيقة؛ قد يتأخر الإشعار قليلاً بسبب توفير البطارية.
- لا يحتاج التطبيق إلى تقليل النوم أو تغيير مواعيد النوم لتحقيق هدفه.
